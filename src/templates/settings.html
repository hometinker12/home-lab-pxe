External DHCP options

Use these only on an existing LAN DHCP server when this box is not answering PXE itself. If DHCP here is enabled (proxyDHCP or authoritative), leave 60/66/67 unset on the other server — this appliance already advertises next-server and the boot file.

Option 60 (PXEClient)

Tells the client and network that a PXE service is present. It is mandatory (set to PXEClient) if that DHCP server and this PXE/TFTP service run on the same physical machine. Do not set option 60 on a separate router if you are using proxyDHCP here.

{{ pxe_hints.vendor_class }}
Option 66 (Next Server)

Specifies the IP address or host name of the TFTP/PXE boot server where the first-stage files reside.

{{ pxe_hints.next_server }}
Option 67 (Boot File Name)

Specifies the initial file name to download over TFTP. This appliance uses iPXE binaries such as undionly.kpxe (BIOS) or ipxe.efi (UEFI), not WDS names like bootx64\wdsnbp.com. Pick one name per architecture (your DHCP UI may have separate BIOS and UEFI classes). If the client already shows the iPXE banner (Proxmox/SeaBIOS ROM), do not use ipxe.efi — that is a UEFI binary and iPXE fails with exec format error. Use TFTP {{ pxe_hints.ipxe_filename }} instead. After iPXE starts, it chains to the HTTP script.

  • BIOS / legacy {{ pxe_hints.bios_filename }}
  • UEFI x86_64 {{ pxe_hints.efi_filename }}
  • UEFI ARM64 {{ pxe_hints.arm_filename }}
  • Already iPXE (Proxmox / SeaBIOS) {{ pxe_hints.ipxe_filename }}
  • iPXE script (HTTP, after iPXE) {{ pxe_hints.ipxe_script }}

Allowed keys: dhcp-option, dhcp-range, dhcp-host, dhcp-boot, dhcp-ignore, dhcp-match, dhcp-vendorclass, dhcp-userclass, pxe-service, pxe-prompt. Scripts and conf-file includes are rejected.

Replace with PEM files

Upload an unencrypted PEM certificate (the server cert first, then any chain) and matching PEM private key. HTTPS reloads after a successful save. The private key is never shown.

Regenerate self-signed certificate

Creates a new self-signed certificate on the SSL volume and reloads HTTPS. Browsers will show a new trust warning.
