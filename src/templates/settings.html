External DHCP options

Use these only on an existing LAN DHCP server when this box is not answering PXE itself. If DHCP here is enabled (proxyDHCP or authoritative), leave 60/66/67 unset on the other server — this appliance already advertises next-server and the boot file.

Option 60 (PXEClient)

Tells the client and network that a PXE service is present. It is mandatory (set to PXEClient) if that DHCP server and this PXE/TFTP service run on the same physical machine. Do not set option 60 on a separate router if you are using proxyDHCP here.

{{ pxe_hints.vendor_class }}
Option 66 (Next Server)

Specifies the IP address or host name of the TFTP/PXE boot server where the first-stage files reside.

{{ pxe_hints.next_server }}
Option 67 (Boot File Name)

Default filename for a single-option DHCP server (UniFi Network Boot, option 67) is {{ pxe_hints.default_filename }} when every client is UEFI. Firmware that is not yet iPXE must get a binary, not WDS names like bootx64\wdsnbp.com and not boot.ipxe (Intel PXE cannot execute a script). BIOS/legacy clients still need undionly.kpxe. Proxmox/SeaBIOS already runs iPXE — those VMs must not receive ipxe.efi unless the guest firmware is OVMF/UEFI. If you pin option 67 to ipxe.efi for UEFI boxes, iPXE 2.0 then loads TFTP autoexec.ipxe (written next to boot.ipxe). Leave 66/67 unset on the other server if this box is already running proxyDHCP on the same L2.

  • Default / UEFI x86_64 {{ pxe_hints.efi_filename }}
  • BIOS / legacy {{ pxe_hints.bios_filename }}
  • UEFI ARM64 {{ pxe_hints.arm_filename }}
  • Already iPXE (Proxmox / SeaBIOS) {{ pxe_hints.ipxe_filename }}

Ubuntu installation media (NFS)

Ubuntu live-server casper media is exported read-only over NFS (userspace).
